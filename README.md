# CV — Currículum Vitae

Currículum bilingüe (español/inglés) escrito en [Typst](https://typst.app).

## Datos de contacto

Los datos privados se mantienen en un fichero `.env`, ejemplo:

```sh
EMAIL=tu@correo.cl
PHONE=+56 9 1234 5678
```

## Estructura

```
src/main.typ        # configuración de página y orquestación
src/components.typ  # componentes reutilizables (secciones, entradas, header)
i18n/en.typ         # contenido en inglés
i18n/es.typ         # contenido en español
```
